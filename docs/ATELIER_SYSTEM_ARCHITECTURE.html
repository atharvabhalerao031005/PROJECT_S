ARCHIVAL MONOGRAPH ABSTRACT // PHILOSOPHICAL FOUNDATIONS REF: SPEC-2026-PRESENCE-V4

Institutional monitoring systems have historically approached classroom environments with surveillance paradigms that undermine student psychological safety, introduce brittle cloud dependencies, and accumulate sensitive biometric liability. Atelier // Presence treats presence telemetry not as surveillance, but as a tactile, ambient pedagogical mirror rooted in computational sovereignty.

By decoupling presence verification from facial identification, the architecture relies on mathematical Euclidean centroid tracking, temporal integral presence state machines, and real-time speech formant filtering (300Hz–3400Hz). Coupled with an air-gapped SQLite WAL database and a rate-protected pedagogical advisor, the system sustains a continuous cognitive equilibrium—fostering deep focus, human rhythm, and pedagogical clarity.

PARADIGM & SECURITY FOUNDATIONS

01 / System Paradigm & Security Architecture

Computational sovereignty through non-identifiable sensory abstraction, zero biometric storage, and SQLite WAL persistence.
1. ZERO BIOMETRIC PERSISTENCE

Incoming base64 camera frames are decoded directly into ephemeral NumPy RAM buffers. No facial embeddings, deep templates, or raw pixel tensors are ever committed to disk or transmitted to third-party endpoints.

2. LOCAL CENTROID TRACKING

Detected faces are abstracted immediately into 2D spatial centroids $(cX, cY)$. Gaze vectors and velocity dynamics reside exclusively in RAM within the TrackedParticipant lifecycle and evaporate upon session termination.

3. AIR-GAPPED SQLITE WAL

Telemetry sessions, verified attendance entries, and pedagogical records persist into a local SQLite database utilizing Write-Ahead Logging (WAL), achieving concurrent, lock-free streaming writes and instant CSV exports.

FIGURE 1.1: SYSTEM TOPOLOGY, IN-MEMORY PROCESSING BOUNDARIES & AIR-GAPPED SQLITE PERSISTENCE
§ 1.1 In-Memory Ephemeral Gating

The architecture strictly enforces an ephemeral memory lifecycle. High-resolution WebRTC frames are decoded in Python memory via OpenCV's C-bindings. As soon as spatial coordinates $(x, y, w, h)$ are mapped to dimensionless centroids $(cX, cY)$, the pixel buffer is garbage-collected.

Participants are designated with session-scoped pseudonymized identifiers (e.g. Participant_01). If a participant leaves the sensory aperture for more than 3.0 seconds, the corresponding track instance is purged, guaranteeing zero retrospective biometric re-identification.

§ 1.2 SQLite WAL Mode Concurrency

High-frequency telemetry logging creates significant I/O pressure in traditional file locks. Atelier // Presence configures SQLite with Write-Ahead Logging:

PRAGMA journal_mode=WAL; PRAGMA synchronous=NORMAL;
Decouples concurrent reader queries from the append-only write loop.

A dedicated shared-memory index (.db-shm) coordinates reader snapshots against the WAL buffer (.db-wal). Administrative users can stream real-time CSV analytics without blocking the 10 FPS telemetry daemon.

SPATIAL TELEMETRY & ATTENDANCE VERIFICATION

02 / Computer Vision & Spatial Centroid Pipeline

Multi-scale Haar feature detection, Euclidean distance matrix bipartite gating, and the 10.0s sustained presence state machine.
CENTROID SPATIAL PROJECTION

For detected bounding boxes $B_k = (x_k, y_k, w_k, h_k)$ from the Haar Cascade classifier, geometric center mass points $(cX_k, cY_k)$ are calculated:

cX_k = x_k + \frac{w_k}{2}, \quad cY_k = y_k + \frac{h_k}{2}
PAIRWISE EUCLIDEAN DISTANCE MATRIX

Between active tracks $i \in \{1 \dots M\}$ and incoming detections $j \in \{1 \dots N\}$, the bipartite distance matrix is evaluated:

D_{i,j} = \sqrt{(cX_{\text{track}, i} - cX_{\text{det}, j})^2 + (cY_{\text{track}, i} - cY_{\text{det}, j})^2}
FIGURE 2.1: CENTROID MAPPING IN CAMERA COORDINATES & DISTANCE MATRIX BIPARTITE GATING
§ 2.1 3.0s Occlusion Grace State Machine

Studio environments naturally involve student head turns, notebook sketching, and temporary book occlusions. Punitive trackers lose tracking state immediately when a face is occluded for a single frame, resetting participant tenure.

Atelier // Presence tracks consecutive missing duration:

\Delta t_{\text{disappeared}} = t_{\text{curr}} - t_{\text{last\_seen}}
If $\Delta t_{\text{disappeared}} \le 3.0\text{ s}$, the track remains active in memory. Deregistration occurs strictly when $\Delta t > 3.0\text{ s}$.

Additionally, brisk hallway walk-bys through open studio doors are filtered via low-pass horizontal velocity gating: $|v_x| = |(cX_t - cX_{t-1}) / \Delta t| > 65\text{ px/s}$.

§ 2.2 10.0s Sustained Presence Integral

To eliminate transient false positives from passing visitors, physical attendance follows a strict temporal integration lifecycle:

\text{Duration}(T_i) = t_{\text{curr}} - t_{\text{first\_seen}}
Duration Window Verification State Ledger Commit
$0.0\text{ s} \le t < 3.0\text{ s}$ Transient (<3s) Ephemeral RAM only
$3.0\text{ s} \le t < 10.0\text{ s}$ Verifying... Telemetry stream only
$t \ge 10.0\text{ s}$ Verified Present Committed to SQLite

Upon crossing the 10.0-second threshold, _auto_commit_verified_attendance() executes an atomic SQLite transaction, logging the participant entry.

HEAD POSE ORIENTATION & SOMATIC DYNAMICS

03 / Head Pose & Optical Motion Inactivity Engine

Dual-engine solvePnP/geometric fallback, angular cosine attention decay, and normalized $64\times 64$ ROI frame differencing.
DUAL-ENGINE HEAD POSE ARCHITECTURE

1. MediaPipe FaceMesh (Primary): Extracts 468 landmarks. Six canonical 3D model coordinates (Nose tip, Chin, Left/Right Eye corners, Left/Right Mouth corners) are mapped via cv2.solvePnP with iterative Levenberg-Marquardt optimization. Rodrigues conversion yields Euler angles $(\theta_y, \theta_p, \theta_r)$.

2. Mathematical Geometric Fallback (Air-Gap): When MediaPipe is uncompiled, estimates orientation from optical axis offsets and bilateral cheek luminance asymmetry:

H_{\text{asym}} = \frac{\mu_{\text{left}} - \mu_{\text{right}}}{\mu_{\text{left}} + \mu_{\text{right}}}, \quad \text{Yaw} = 55.0 \cdot H_{\text{asym}} + 12.0 \cdot x_{\text{norm}}
ANGULAR COSINE ATTENTION DECAY

Natural human attention does not collapse precipitously at small head rotations. Atelier // Presence models gaze orientation through a continuous cosine decay:

\text{Score}(\theta) = \begin{cases} 100.0 & \theta \le 15^\circ \\ 25.0 + 37.5 \left(1 + \cos\left(\pi \frac{\theta - 15}{30}\right)\right) & 15^\circ < \theta \le 45^\circ \\ 25.0 & \theta > 45^\circ \end{cases}
Where $\theta = \max(|\theta_y|, |\theta_p|)$. Protected note-taking floor: $\ge 70.0\%$.
FIGURE 3.1: 3D HEAD POSE ORIENTATION CONES, COSINE ATTENTION DECAY, AND MOTION ENERGY PENALTIES
§ 3.1 Note-Taking & Downward Gaze Protection

Standard computer vision systems routinely penalize participants who glance down at their physical notebooks, misclassifying scholarly drafting as inattention. Atelier // Presence detects downwards tilt by computing the facial vertical luminance gradient:

R_{TB} = \frac{\mu_{\text{forehead}}}{\mu_{\text{chin}}}, \quad \text{is\_note\_taking} = (dy > 4.5\text{ px}) \lor (R_{TB} < 0.77)

When active, the participant is classified as Note-Taking / Downward Focus, and the attention score is clamped to a healthy pedagogical baseline ($\ge 70\%$).

§ 3.2 ROI Optical Flow Differencing

Each tracked face ROI is scaled to a standard $64 \times 64$ grid and filtered with a Gaussian kernel ($\sigma=1.0$). Absolute differencing isolates microscopic motor gestures:

E_{\text{ROI}} = \frac{1}{64 \times 64} \sum_{x,y} \mathbb{I}(|I_t(x,y) - I_{t-1}(x,y)| > 14)

Continuous postural stagnation for over 8.0 seconds accumulates an inactivity penalty, gently lowering overall equilibrium and alerting the pedagogical agent to recommend a posture break.

ACOUSTIC SPECTROMETRY & DSP PIPELINE

04 / Acoustic Intelligence & WebAudio DSP Pipeline

WebAudio AnalyserNode PCM streaming, Librosa RMS/dBFS energy, and the 16-band logarithmic spectral equalizer.
ROOT-MEAN-SQUARE (RMS)
\text{RMS} = \sqrt{\frac{1}{N}\sum_{i=1}^N x_i^2}

Real-time energy over $N=512$ float32 PCM samples in $[-1.0, 1.0]$.

DECIBELS FULL SCALE (dBFS)
\text{dBFS} = 20\log_{10}(\max(\text{RMS}, 10^{-6}))

Calibrated silence threshold set at $-42.0\text{ dBFS}$ floor.

SPECTRAL CENTROID ($f_c$)
f_c = \frac{\sum_k f_k |X(k)|}{\sum_k |X(k)|}

Center of mass discriminating voice from ambient HVAC noise.

§ 4.2 Speech Formant Discrimination

Unlike naive volume meters that spike when a door slams or paper rustles, the AudioAnalyzer evaluates acoustic qualification across two orthogonal axes:

\text{is\_speech} = (\text{dBFS} > -42.0\text{ dBFS}) \land (300\text{ Hz} \le f_c \le 3400\text{ Hz})
True speech requires both sufficient decibel energy and spectral centroid alignment.

When active speech is detected, the acoustic score feeds into the Multimodal Equilibrium Formula at 20% weight, signaling participatory studio dialogue.

§ 5.1 Rate-Protected Agentic AI Gateway

Pedagogical recommendations are synthesized via cloud LLMs without exposing telemetry streams to rate exhaustion:

  • Groq Llama 3.1 8B Instant: Ultra-low latency (~180ms), JSON output schema.
  • Gemini 3.5 Flash / Flash-Lite: Deep multimodal reasoning with thinking budget capped.
  • 10-Second Calibrated Throttling Cache: External LLM calls fire only if the engagement trend shifts or after 10.0s elapsed cooldown.
  • Output Cap: Strictly enforced at max_tokens = 120.
§ 5.2 Deterministic 6-State Offline Matrix

If network connectivity fails or API rate quotas are exceeded (HTTP 429), the engine defaults instantly to the deterministic matrix:
